## 🟠 Problem formulation appears to be buggy (30 problems)

**Every entry in this table has a verified model**: its solution file contains a Lean model of the problem exactly as written in TPTP v10.0.0 (axioms plus negated conjecture), checked with `Tools/check_lean_model.sh`. So the status of each problem as written is settled: it is not a theorem. The reason, however, is the formulation: a symbol in the conjecture has no (or too few) axioms, or a hypothesis is missing. The suggested change is therefore to **fix the problem**; the intended problem is presumably a theorem (details in the % Status line of each solution file).
