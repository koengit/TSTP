## ⚠️ The axiom set SET004-0 + SET004-1 + NUM004-0 is inconsistent

Clause `rest_of4` of NUM004-0 puts (u, restrict(x,u,universal_class)) into rest_of(x) for every u in domain_of(x), even when restrict(x,u,universal_class) is a proper class, while `rest_of1` makes rest_of(x) a subclass of cross_product(universal_class,universal_class), whose pairs have set components (`cartesian_product2`). With x = cross_product(universal_class,universal_class) and u = {null_class}, u x V would be a set, hence so would its range, the universal class; then diagonalise(element_relation) would be a set (Russell's paradox). The 78-step refutation uses only the axioms and is GDV-verified ([NUM289-1](Solutions/NUM/NUM289-1/), the axioms alone). Consequences for the 277 TPTP v10.0.0 problems that include NUM004-0: the 7 with status Satisfiable are wrong (all listed below), the 197 with status Unknown are Unsatisfiable (all listed below; 123 of them also with a direct proof that does not rely on the inconsistency), and the 73 Unsatisfiable ones are trivially so. SUGGESTED FIX: add the literal `~ member(V,universal_class)` to `rest_of4` (the restriction must be a set, as the class existence theorem in the clause's comment requires); requiring function(X) would also do. **With this fix the axioms are consistent**: a Lean model of SET004-0 + SET004-1 + the fixed NUM004-0 is in [Fixed/NUM004-0](Fixed/NUM004-0/) (check with `Fixed/NUM004-0/check.sh NUM289-1`). Of the proofs here, the 123 direct proofs of Unknown problems and the proofs of NUM036-1, NUM097-1, NUM109-1, NUM173-1, NUM175-1 and NUM252-1 do not use `rest_of4`, so they remain valid with the fix. Of the 73 Unsatisfiable problems, 63 have a TSTP derivation that does not use `rest_of4`. One, [NUM219-1](https://seetptp.tptp.org/file/TPTPWorld/TPTP/Problems/NUM/NUM219-1.p) (domain_of(rest_of(u)) = domain_of(u), rating 1.00), is false with the fix (Lean countermodel in the same folder, u = V × V), so it holds only through the inconsistency.
